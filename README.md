# AWS S3 Static Website

A static website deployed using Amazon Web Services (AWS) S3 Static Website Hosting.

## Project Overview

This project demonstrates how to host a static HTML website using Amazon S3 and make it accessible through an S3 website endpoint.

The project also uses Git and GitHub for source-code version control.

## AWS Services Used

* Amazon S3
* S3 Static Website Hosting
* S3 Bucket Policy

## Technologies & Tools

* HTML5
* Amazon S3
* Git
* GitHub
* Windows Command Prompt

## Deployment Process

1. Created an Amazon S3 bucket.
2. Configured static website hosting.
3. Uploaded index.html to the S3 bucket.
4. Configured bucket permissions and bucket policy.
5. Tested the S3 website endpoint.
6. Initialized a Git repository locally.
7. Committed the project files using Git.
8. Created a public GitHub repository.
9. Pushed the project to GitHub.
