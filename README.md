# AWS S3 Static Website

A simple static website deployed using **Amazon Web Services (AWS) S3 Static Website Hosting**.

## 📌 Project Overview

This project demonstrates how to host a static HTML website on Amazon S3 and make it accessible through a public website endpoint.

The project also uses **Git and GitHub** for source-code version control.

## ☁️ AWS Services Used

* **Amazon S3** — Object storage and static website hosting
* **S3 Bucket Policy** — Configured to allow public access to website objects

## 🛠️ Technologies & Tools

* HTML5
* Amazon S3
* Git
* GitHub
* Windows Command Prompt

## 🚀 Deployment Process

1. Created an S3 bucket.
2. Configured the bucket for static website hosting.
3. Uploaded `index.html` to the S3 bucket.
4. Configured the required bucket permissions and bucket policy.
5. Enabled public access for the website objects.
6. Tested the S3 website endpoint.
7. Initialized a Git repository locally.
8. Committed the project files using Git.
9. Created a public GitHub repository.
10. Pushed the project to GitHub using Git.
